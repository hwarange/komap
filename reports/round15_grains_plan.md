# 15단계: 외부 결정립 데이터 전이학습

2026-10-08 KST. 사용자가 대회용으로 안정적인 방안을 선택해 실행하도록 승인했다.
현재 진행 중인 14단계 MiT 실험을 유지하고, 비는 GPU에서만 외부 실험을 진행한다.

## 데이터 검수 완료

- 출처: [Artificial Grains and Real Grains](https://www.kaggle.com/datasets/peterwarren/voronoi-artificial-grains-gen), version 4, CC0.
- 실제 RG/RGMask **480쌍**만 사용한다. 합성 AG와 자동 생성 마스크는 사용하지 않는다.
- 실제 크기는 **400×400**이다. 소개 글의 400×300과 차이가 있어 파일 기준으로 설정했다.
- 검은 수작업 선이 결정립 경계다. JPEG 강도 <128을 임시 이진 라벨 1, 나머지를 0으로 변환했다.
  이 라벨은 KoMaP의 Al3Ni 등 상 이름을 의미하지 않는다.
- 20개 파일명 그룹에서 사진·마스크 정렬과 경계 의미를 시각적으로 확인했다.
- 파일명 그룹은 40개이며, 원본 촬영 장수가 40장이라고 단정하지 않는다.
  같은 그룹의 12개 조각을 묶어 seed 0으로 **학습 32그룹/384쌍, 검증 8그룹/96쌍**으로 나눴다.
- 전체 사진에 대해 픽셀 해시와 8가지 회전·반전 pHash를 비교했다. 정확한 중복과 pHash 거리 8 이하의
  그룹 간 유사 후보는 없었다. KoMaP 학습·검증·평가 사진 100장과 비교한 후보도 없었다.
  이 검사는 알려지지 않은 시야 중첩까지 완전히 배제한다는 뜻은 아니다.
- 산출물: 서버 `external/kaggle_grains_seg/audit.json`, `manifest.json`, 변환 PNG.
  로컬 검수 사본: `runs/review15/data_audit/`.

## 학습과 자원 배치

1. 14단계 대기 작업 10개가 모두 GPU에 배정된 후 시작한다. GPU 메모리 <1000MiB,
   사용률 <10%를 15초 간격으로 두 번 확인한 GPU만 사용한다. 기존 작업을 중단하지 않는다.
2. ImageNet 초기 MiT-B2 U-Net을 결정립 경계 이진 분할로 사전학습한다.
   **20에폭, crop/tile 384, 원본 배율(width 0), batch 8, 이미지당 4 crop,
   에폭당 최대 200 update, seed 0, 90도 회전/반전, 기본 밝기 증강, 경계 가중치 2, BF16**.
   현재 384장에서는 에폭당 192 update, 총 3840 update다. 마지막 20에폭 가중치를 고정 사용한다.
3. 사전학습 손실이 유한하고, 외부 검증 TTA 경계 IoU가 0.10 이상일 때만 미세조정한다.
   외부 이진 점수에 없는 상의 NaN은 구조상 예상되며, 손실/경계 IoU의 NaN은 실패로 처리한다.
4. 4상 출력층을 초기화하고 **fold 0·1**을 먼저 학습한다.
   기존 `x2_mit_bw_r90`의 각 fold 설정을 그대로 읽어 재사용한다.
   60에폭, seed, 1024 crop, 2배 해상도, 증강, batch, worker 6, 학습률이 동일하다.
   출력 경로 외의 차이는 외부 초기 가중치와 출력층 초기화뿐이다.
5. 아래 pilot 기준을 모두 통과하면 완료한 2개 fold를 재사용하고 나머지 2·3·4를 병렬 학습한다.
   미통과 또는 오류 시 중단 이유를 남긴다. 다른 설정으로 계속 탐색하지 않는다.

## 미리 고정한 pilot 진행 기준

기존 MiT와 같은 사진의 마지막 60에폭 TTA+후처리 점수를 비교한다.
pilot은 36장/28합금이며, fold별 합금 그룹을 복원 추출한 bootstrap 10,000회(seed 0)를 사용한다.

- 평균 개선 ≥ **+0.15%p**.
- fold 0과 1 각각 개선 >0.
- 그룹 bootstrap 95% 구간 하한 ≥ −0.15%p.
- 저대비 사진과 Eutectic Si 변화 각각 ≥ −0.15%p.
- 다른 상 변화 각각 ≥ −0.30%p.

이 기준은 나머지 fold 계산을 진행할지 판단하는 기준이며 제출 채택이나 개선 확정 기준이 아니다.
pilot을 보고 기준을 바꾸지 않는다.

## 전체 검증과 제출 후보 판단

전체 90장 결과와 pilot에 쓰지 않은 fold 2·3·4를 따로 보고한다.
기존 sub6의 같은 비중 MiT+UNet++에 대해 아래 두 조합을 미리 고정해 비교한다.

- MiT를 외부 초기값 MiT로 교체한 1:1 조합.
- 기존 MiT+UNet++에 외부 초기값 MiT를 더한 1:1:1 조합.

제출 검토 후보가 되려면 전체 개선 ≥0.05%p, 전체 및 비pilot 그룹 CI 하한 >0,
비pilot 3개 fold 각각 개선, 저대비 및 Eutectic Si 비악화, 다른 상 하락 ≤0.1%p를 모두 만족해야 한다.
14단계까지 포함한 앙상블 선택 결과도 별도로 기록한다.
pilot에서 선별한 전체 CV는 탐색 결과로 표현하며 독립 검증처럼 표현하지 않는다.
자동으로 sub6을 교체하거나 공식 제출하지 않는다. 실제 결과와 형식 검증을 확인하고 채택한다.
