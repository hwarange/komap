두 실험 모두 같은 90장 합금 단위 5-fold, seed, 입력 크기, 모델 구조,
감마/노이즈 증강, 90도 회전/반전을 유지한다. 고해상도 MiT는 GPU당 하나만 실행.

| 실험 | 바꾸는 설정 | 목적 |

| `x2_mit_bw_r90_sj0` | 크기 증강 폭 0.15 → 0 | 얇은 구조를 변형하지 않는 것이 도움이 되는지 확인 |

20:52:49 실행 시작. 첫 실험 fold 0~3이 GPU 0~3에서 시작했다.
네 작업 모두 첫 에폭의 손실이 유한하며, 측정 최대 학습 메모리는 각각 26.63GB다.
기존 MiT와 설정을 대조하여 학습 에폭만 60에서 120으로 바뀐 것을 확인했다.
기존 시간 기준 전체 학습은 약 3~4시간 예상이며 실제 속도에 따라 달라진다.

## 증강과 외부 데이터 판단

새 외부 데이터는 적용하지 않았다. 감마·노이즈의 효용은 기존 실험에서
확인됐지만, 탄성 변형·cutout·mixup·CutMix는 두 구조 모두에서 악화했다.
해상도와 구조가 달라진 MiT에서 크기 증강 하나만 다시 비교하기로 했다.

실제 Al 광학현미경 자료인 [MicroAl](https://github.com/neulmc/MicroAl-Dataset)은
10/7에도 검토한 후보다. 저장소는 학술 연구 전용, 상업적 사용 제한을 명시하며,
표의 공개 데이터 규모와 샘플 공개 안내가 함께 존재한다. 완전한 외부 데이터가
즉시 확보됐다고 판단하지 않았다. 관련 [PSCL](https://github.com/neulmc/PSCL)은
198장의 376×376 금속조직 사진을 안내한다. 현재 4상 문제와 동일한 라벨은 아니다.

이미 시험한 MICAST 사전학습은 −0.42, MicroSteel은 −0.09였다.
추가 외부 데이터 실험은 촬영 방식, 라벨 의미, 배율, 실제 다운로드 가능 범위를
확인한 뒤 별도 계획으로 제안한다. 이번에는 사용자가 MiT 두 실험을 우선 선택했다.
