# 본선 발표 순서안 (2026-10-29 KINTEX)

`KoMaP_본선발표_v4` 자료를 바탕으로 순서를 다시 짠 안입니다.
목표는 "EDA → 1차 모델 → 원인 분석 → 개선 → 다시 원인 분석 → 활용"의 문제 해결 흐름을 보여 주는 것입니다.

- 발표 시간은 10분으로 가정했습니다. 주최측에 실제 시간을 확인하세요.
- 목차 슬라이드는 넣지 않습니다.
- 괄호 안의 "(v4 n번)"은 지금 v4 PDF의 슬라이드 번호입니다.
- **[새 장]**은 새로 만들어야 하는 슬라이드입니다.
- 모든 숫자는 보고서와 분석 파일에서 확인했습니다. 숫자를 바꾸거나 새로 넣을 때는 아래 "숫자 출처"를 보세요.

## 1막: EDA로 규칙 만들기 (2분)

### 3. 사진마다 다른 밝기 → 사진별 정규화 (v4 3번 수정)
- **화면**: v4 그림 그대로
- **아래 문구 변경**
  - 바꿀 문구: "저대비 사진 mIoU 84.3% (나머지 79.4%)"
  - 새 문구: "저대비 사진: train 23/70장, **test 6/10장**"
- **이유**: 84.3%는 최종 결과라 EDA 단계에 두면 순서가 맞지 않습니다. 11번으로 옮깁니다. EDA 단계에서는 "test가 저대비 위주라 꼭 해결해야 했다"가 더 강한 근거입니다.

### 4. 같은 시야, 다른 해상도 (v4 4번)

- **말할 것**: "675px 사진의 공정 Si는 1.9px입니다. 정답 마스크조차 절반 해상도로 줄였다 되돌리면 73.8점입니다."
- **문구 수정**: "정답도 73.8%" → "정답 마스크도 73.8"

### 5. 그래서 돋보기 (v4 5번 보강)
- **화면 수정**
  - 배율 옆에 모델 이름을 붙입니다: "675px: MiT ×4 · UNet++ ×6", "1278px: MiT ×2 · UNet++ ×3"
  - 핵심 한 줄을 추가합니다: **"675px 1.9px × 4 = 7.6px ≈ 1278px 3.8px × 2 = 7.6px"**
- **말할 것**: "원본 폭에 따라 정수 배율로 키워서 어느 사진이든 조직이 비슷한 두께로 보이게 했습니다."

### 6. 측정한 사실을 규칙으로 (v4 6번)
- **화면**: 카드 3장은 그대로 두고 설명 문구만 정리합니다.

  | 카드 | 측정한 사실 | 설계 규칙 |
  |---|---|---|
  | 경계 가중 ×3 | 공정 Si의 63%가 경계 위 | 경계 픽셀에 3배 가중 |
  | 초정 Si 후처리 | 초정 Si는 있으면 사진의 1.53% 이상 | 작은 오탐 조각 제거 |
  | 합금 단위 검증 | train과 val에 같은 합금 7종이 겹침 | 합금 단위로 나눠 5-fold 검증 |

- 세 번째 카드 문구는 "train·val에 같은 합금 7종 겹침 → 합금 단위로 나눠 검증"으로 바꿉니다.
- **초정 Si 후처리는 여기서 한 번만 소개합니다.** 발표 마지막 단계로 두지 않습니다.

## 시간이 부족할 때 (19장 → 16장)
1. 4번과 5번을 한 장으로 합칩니다(왼쪽 두께 막대, 오른쪽 배율 규칙).

## 발표에서 조심할 말
- **"1차 → 최종 +1.85"는 여러 개선을 합친 결과입니다.** 해상도로 몇 점, 경계 가중으로 몇 점처럼 항목별로 나눠 말하지 않습니다. 항목별 수치는 validation을 학습에 섞던 개발 초기 결과라 쓰지 않습니다.
- 1차 모델의 78.77도 TTA와 후처리를 포함한 점수라 최종과 공정하게 비교할 수 있습니다. 1차 모델은 validation 점수로 가장 좋은 epoch를 고른 값이라 오히려 조금 후하게 나온 숫자입니다.
- **A71 사진은 그림으로만 쓰고, 1차와 최종 점수를 비교하지 않습니다.** 이 사진은 1차 61.8에서 최종 57.7로 오히려 내려갔습니다.
- validation 20장은 모델 선택에 쓴 자료라 완전히 독립된 시험이 아닙니다. 질문받으면 "그래서 합금을 분리한 내부 5-fold(80.78)를 함께 제시했다"고 답합니다.
- 예상 질문과 답은 `reports/qa_prep_final.md`에 있습니다.
