# 6단계 계획: 남은 개선 후보 적용 → 3차 제출본

- **작성:** 2026-10-06
- **출발점:** 2차 제출본(`sub2`) CV **79.96** (16개 실험 × 5-fold 앙상블 + Si 덩어리 분류기)
- **목표:** CV 약 80.3~80.5 (현실적인 추가 개선 +0.3~0.6)
- **원칙**
  - 측정으로 효과를 먼저 확인하고, 비싼 작업은 그다음에 해요.
  - 효과가 확인된 것만 3차 제출본에 넣어요.
  - `sub2`는 항상 안전한 대비책으로 남겨 둬요.
- **GPU 예산:** 약 5~6시간 (L40S 4장 × 동시 2작업). "두 번째 기회" 실험(B4)과 학습 곡선 2구조 측정 포함

---

## 전체 흐름

```
A. 측정 (짧고 싸다)            B. 새 앙상블 재료 (5-fold)         C. 90장 전체 학습        D. 3차 제출본
 A1 학습 곡선 ─────────────┐   B1 2배 해상도 + UNet++              (A1이 긍정적일 때)      앙상블 재구성
 A2 크기 키운 TTA ─────────┤   B2 MicroNet 인코더 (+ 대조군)  ──▶  상위 구성 × 시드 3개 ──▶ + Si 분류기 재학습
                           └──▶ B3 EfficientNetV2 / HRNet                                     + 검증 → sub3
```

A와 B는 동시에 돌릴 수 있어요. C는 A1 결과를 보고 결정해요.

---

## A. 측정 단계 (약 40분)

### A1. 학습 곡선: "90장으로 학습하면 얼마나 좋아질까?"
- **왜:** 90장 전체로 학습한 모델은 검증할 수 없어요. 효과가 있을지 미리 근거가 필요해요.
- **방법:** 각 fold의 학습 데이터(72장)를 **합금 단위로 75%(54장), 50%(36장)만** 써서 학습하고, 72장으로 학습한 결과와 비교해요.
  - 모델: `cnx_bw`(빠르고 시드 잡음 0.09) **와 `unetpp_bw`(UNet++) 두 구조**
  - 한 구조로만 재면 다른 구조에서의 데이터 효과를 놓칠 수 있어서 두 구조로 재요(거짓 음성 방지)
  - 2개 수준 × 2개 구조 × 5-fold = 20개 작업, 약 30분
- **코드 추가:** `train.py --train-frac 0.75` (합금 그룹 단위로 무작위 제외, 시드 고정)
- **판단 기준:**
  - 54 → 72장에서 **+0.3 이상** 오르면 72 → 90장에서도 +0.2 이상을 기대할 수 있어요 → **C 단계 진행**
  - 거의 안 오르면 C 단계는 건너뛰어요 (데이터 양이 병목이 아니라는 뜻)

### A2. 크기 키운 TTA (학습 없음, 약 20분)
- **왜:** 지금 TTA는 회전·반전 8방향뿐이에요. 사진을 1.25배로 키워 예측한 결과를 함께 평균내면 경계가 더 안정될 수 있어요.
- **주의:** 축소(0.75배)는 쓰지 않아요. 1~2px 구조를 지운다는 걸 저해상도 흉내 실험에서 확인했어요.
- **방법:** 저장된 모델(`unetpp_bw_e120_r90`, `cnx_bw`)로 90장 OOF를 원본 + 1.25배(각 8방향)로 예측해 비교해요.
- **판단 기준:** +0.1 이상이고 95% 구간이 0보다 위면 제출 파이프라인에 넣어요. 예측 시간은 약 2.5배가 돼요.

## B. 새 앙상블 재료 (5-fold, 약 2.5시간)
모든 실험은 경계 가중(`--bw 2`) + 90° 회전(`--rot rot90`) + 예측 확률 저장(`--save-oof`) 조건이에요.

| 실험 | 설정 | 왜 | 비교 대상 |
|---|---|---|---|
| **B1 `x2_unetpp_bw_r90`** | UNet++ (ResNet34) + 2배 해상도 + crop 1024 | 2배 해상도(+0.32)와 UNet++(최고 단일 모델)를 아직 함께 써 보지 않았어요. **최고 단일 모델 후보** | `x2_c1024_bw_r90`, `unetpp_bw_e120_r90` |
| **B2a `unetpp_bw_r90`** (대조군) | UNet++ (ResNet34, ImageNet) 60에폭 | MicroNet 효과를 공정하게 재기 위한 기준 | |
| **B2b `mn_r34_unetpp`** | UNet++ + **MicroNet ResNet34** (ImageNet → 현미경 사전학습) | OM 사진 약 1/3을 포함한 현미경 사전학습의 효과 | B2a (사전학습만 다름) |
| **B2c `mn_sxt50_unetpp`** | UNet++ + **MicroNet SE-ResNeXt50** | 저자가 추천한 정확도 높은 MicroNet 인코더 | B2a |
| **B3a `effv2s_unetpp`** | UNet++ + EfficientNetV2-S | 앙상블 다양성 (1/2 해상도 연결 있음) | `unetpp_bw_e120_r90` |
| **B3b `hrnet_unet`** | U-Net + HRNet-W18 | 고해상도 흐름을 유지하는 구조. 앙상블 다양성 | 〃 |

- **코드 추가:** MicroNet 가중치를 불러오는 함수(`build_model`에 `micronet:` 접두어)
  - 공식 패키지는 smp를 0.2.1로 내려 버려서 쓰지 않아요.
  - S3에서 가중치를 직접 받아 인코더에 넣어요(조사 에이전트가 동작 확인한 방식).
  - **불러온 뒤 가중치 일치를 꼭 확인**해요(DINOv3 때처럼).
- **실행 전 확인:** B1은 UNet++에 1024 crop이라 메모리가 커요. 짧은 테스트로 메모리와 속도를 먼저 재요.
- **판단 기준:** 단일 점수보다 **앙상블에 넣었을 때 정직한 추정이 오르는지**로 판단해요(B3는 다양성용).

### B4. "두 번째 기회" 실험 (거짓 음성 방지, 약 1시간 추가)
"싸게 재 보고 효과 있는 것만 넣는다"는 원칙은 **효과가 있는데 놓치는 경우**를 만들 수 있어요(사용자 지적, 10/6). 실제로 Si 덩어리 분류기는 첫 설정(+0.02)만 보고 버릴 뻔했어요(다른 설정에서 +0.10). 그래서 **실패 원인이 "설정 문제"로 설명되는 아이디어**는 다른 설정으로 한 번 더 시험해요.

| 실험 | 첫 결과 | 이번 설정 | 실패 원인 가설 |
|---|---|---|---|
| `m_dinov3_lr` | −0.20 (학습률 3e-4) | 인코더 학습률 1/10 (3e-5), 디코더는 3e-4 | 사전학습 특징이 높은 학습률에 덮어써짐 |
| `m_skel_w015` | −2.44 (가중치 1.0) | 가중치 0.15 | 재현율만 강제하는 손실이 너무 강해 과다 예측 (Eutectic Si 1.5배) |
| `cnxS_bw_e120` | −0.07 (60에폭) | ConvNeXt-Small 120에폭 | 큰 모델은 더 오래 학습해야 함 |

- 모두 경계 가중 + 90° 회전 조건, 5-fold로 돌려요.
- **판단:** 단일 점수뿐 아니라 앙상블 기여로도 봐요.
- **코드 추가:** 인코더와 디코더의 학습률을 따로 주는 옵션 (`--enc-lr-mult`)

### 판단 기준 보완 (거짓 음성 줄이기)
- **단일 모델로 채택:** +0.1 이상, 95% 구간이 0보다 위 (보수적)
- **앙상블 재료로 채택:** 단일 점수가 낮아도, 앙상블에 넣었을 때 정직한 추정이 떨어지지 않고 **다양성을 주면** 넣어요. 앙상블 선택에서 단일 점수가 낮은 `unet_mit`이 매번 뽑혔던 것처럼요.
- **받아들이는 한계:** 시드 잡음(0.09~0.35)보다 작은 효과는 90장으로는 확인할 수 없어요.

## C. 90장 전체로 학습 (A1이 긍정적일 때만, 약 1.5시간)
- **대상:** 앙상블에서 자주 뽑힌 서로 다른 구성 4~5개
  - `unetpp_bw_e120_r90`, `x2_c1024_bw_r90`, `unet_mit_bw_r90`, `cnx_bw_e120`
  - B 단계에서 가장 좋았던 것 1개
- **방법:** 구성마다 **시드 3개**로 90장 전체 학습해요. 검증할 수 없으니 시드를 여러 개 써서 "가끔 크게 틀리는 사고"의 위험을 낮춰요.
- **코드 추가:**
  - `train.py --full` (검증 없이 90장 학습, `last.pt`만 저장)
  - `launch.py`가 완료를 인식할 표시 파일
- **안전 점검 (검증 대신)**
  1. 학습 데이터 90장 예측 점수가 비정상적으로 낮지 않은지 (학습이 깨졌는지 확인)
  2. 평가 10장 예측이 `sub2`와 얼마나 다른지 (사진당 2% 이상 다르면 원인 확인)
  3. 시드 3개끼리 예측 일치도
- **제출본에 섞는 방법:** 구성마다 "fold 모델 5개 평균"과 "전체 학습 모델 3개 평균"을 1:1로 섞어요.
  - 이 비율은 검증할 수 없어서 원칙에 따라 정했어요. 보고서에 그 이유를 적어요.

## D. 3차 제출본 조립 (약 40분)
1. **앙상블 재구성:** 기존 16개 + B 단계 모델로 `ensemble.py`를 돌려 "전체 평균"과 "중첩 검증 탐욕적 선택"을 비교해요. 정직한 추정이 높은 쪽을 고르고, 비슷하면 고르는 과정이 없는 전체 평균을 써요.
2. **Si 덩어리 분류기:** 새 앙상블 구성으로 다시 학습하고, 중첩 검증으로 효과를 확인해요(확신 80% 기준).
3. **A2가 채택됐다면** 크기 키운 TTA를 적용해요.
4. **C 단계를 했다면** 전체 학습 모델을 섞어요.
5. **검증**
   - 제출 코드로 OOF 재현 (fold 모델 부분)
   - 형식 검사
   - 분류기가 바꾼 픽셀 비율
   - `sub2`와의 차이
6. **결정:** 3차 제출본의 정직한 추정이 `sub2`보다 확실히 높을 때만(+0.1 이상) 최선으로 교체해요. 아니면 `sub2`를 유지해요.

## 자기 점검 (계획 단계에서 미리)
0. **지금까지 "효과 없음"을 빨리 결론 낸 경우가 있었어요.** DINOv3와 Skeleton 손실은 설정 하나만 보고 판단한 걸 알면서도 재시도를 미뤘어요. 사용자 지적을 받고 B4 "두 번째 기회" 실험과 보류 목록으로 보완했어요.
1. **기대 효과는 추정이에요.** 이 데이터에서는 "흔히 효과가 있다"는 방법이 여러 번 실패했어요. 그래서 A 단계 측정과 판단 기준을 먼저 두었어요.
2. **학습 곡선 외삽은 거칠어요.** 54 → 72장의 개선 폭으로 72 → 90장을 추정하는 건 근사예요. 그래서 C 단계는 시드 여러 개와 안전 점검으로 위험을 줄여요.
3. **MicroNet은 이 규모(90장)에서 ImageNet과 비슷했다는 보고가 있어요.** 그래서 단일 성능보다 다양성에 기대를 걸어요. 대조군(B2a)으로 순수 효과를 따로 재요.
4. **B1은 계산이 무거워요.** 메모리·시간을 먼저 재고, 너무 무거우면 crop 768로 줄여요.
5. **여러 실험을 동시에 비교하니** 우연히 좋아 보이는 결과가 나올 수 있어요. 채택은 95% 구간과 앙상블의 정직한 추정을 기준으로 해요.
6. **평가 사진이 10장이라 운에 따른 흔들림(±2~3%p)이 남은 개선 폭보다 커요.** 그래서 정확도 작업은 10/7까지로 끊고, 나머지 시간은 보고서에 쓰는 일정으로 짰어요.
