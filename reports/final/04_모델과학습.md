# 4. 모델과 학습

## 4.1 최종 파이프라인 (sub5)
```
입력 사진 ─ 흑백·p1–p99 정규화·정수 배율
   │
   ├─ ① 4상 앙상블: 27개 실험 × 5-fold = 135개 모델, 모델마다 8방향 TTA, 확률 평균
   ├─ ② Eutectic Si 전용 모델 2종(UNet++ / ConvNeXt, 2배 해상도) × 5-fold
   └─ ③ Al3Ni 전용 모델 (UNet++, 2배 해상도) × 5-fold
   │
   ├─ Eutectic Si 섞기: P(SiE) ← 0.6·앙상블 + 0.4·전용 모델 2종 평균 (나머지 상은 합이 1이 되도록 비율 조정)
   ├─ Al3Ni 섞기:      P(Al3Ni) ← 0.7·앞 결과 + 0.3·Al3Ni 전용 모델
   ├─ 가장 높은 확률의 상 선택 → Primary Si 후처리 (작은 조각 제거)
   └─ Si 덩어리 분류기: Si 덩어리마다 Primary/Eutectic 재판정 (확신 80% 이상일 때만)
   │
원래 해상도 4색 마스크
```
- 섞는 비율(0.4, 0.3)과 분류기의 효과는 모두 중첩 교차검증으로 정했다(5장).
- `sub5_full`은 여기에 90장 전체로 학습한 모델(6개 구성 × 시드 3개)을 해당 구성의 fold 모델 평균과 1:1로 섞은 판이다(전체 비중 약 10%). 검증할 수 없어 안전 점검(학습 사진 점수, 시드 간 일치도, 차이 비율)으로 대신했다.

## 4.2 분할 모델
- **기본 구조:** U-Net / UNet++ (segmentation_models_pytorch 0.5). 인코더는 ImageNet 사전학습을 쓰고, 1채널 입력에 맞게 RGB 가중치를 합쳤다.
- **앙상블에 들어간 27개 실험의 구성**

| 계열 | 인코더 | 비고 |
|---|---|---|
| UNet++ | ResNet34 (60/120 에폭, 90° 회전 등), ResNet50, EfficientNetV2-S, MicroNet ResNet34·SE-ResNeXt50 | 가장 꾸준한 구조 |
| U-Net | ConvNeXt-T (여러 설정), ConvNeXt-S, DINOv3 ConvNeXt-T, HRNet-W18, MiT-B2 | 서로 다른 실패 양상 → 다양성 |
| **2배 해상도** | U-Net ResNet34 (조각 1024), **UNet++ ResNet34 (60·120 에폭, 시드 2개)** | **최고 단일 모델 80.03** |

- 단일 점수가 낮은 모델도 앙상블에서 다양성을 준다. 실제로 자동 선택이 단일 점수가 낮은 EfficientNetV2·ConvNeXt-S를 꾸준히 골랐다. 최종적으로는 **고르는 과정이 없는 전체 평균**을 쓴다. 자동 선택 구성(G8)과 전체 평균(A26)은 전용 모델·분류기를 더한 뒤 정직한 추정이 같았고(둘 다 약 80.19), 그렇다면 한 모델에 덜 의존하는 쪽이 안전하기 때문이다.

## 4.3 손실과 학습 설정
| 항목 | 설정 | 근거 |
|---|---|---|
| 손실 | 교차엔트로피 + Dice | |
| **경계 가중** | 정답 경계 1 px 이내 픽셀의 CE에 3배 가중(전체 평균 1로 정규화) | 오답의 79%가 경계. +0.2~0.4, 다른 개선과 효과가 더해짐 |

## 4.4 예측
- **슬라이딩 윈도우:** 타일 512 px(2배 해상도는 1024 px), 겹침 128 px, 타일 가장자리보다 가운데를 더 믿도록 가우시안 가중
- **8방향 TTA:** 90° 회전 4가지 × 좌우 반전. 단일 모델에서 약 +0.9로 가장 큰 단일 효과
- 2배로 키운 예측은 2×2 블록 평균으로 원래 해상도로 되돌린다(정수 배율이라 정확)

## 4.5 후처리 ① Primary Si 오탐 제거 (EDA 기반)
- 이미지 면적의 0.01% 미만인 Primary Si 조각은 지운다. Primary Si는 있으면 항상 1.53% 이상이고, 작은 조각은 정답 Primary Si 픽셀의 약 0%만 차지한다.
- 남은 Primary Si가 전체의 0.5% 미만이면 모두 지운다(Primary Si가 없는 사진 대응).
- 지운 픽셀은 Primary Si를 뺀 나머지 상 중 확률이 가장 높은 상으로 바꾼다.

## 4.6 후처리 ② Si 덩어리 분류기 (금속학 특징)
- **동기:** 경계에서 떨어진 Eutectic Si 픽셀의 15.8%가 Primary Si로 예측됐다. 두 상은 같은 결정이라 밝기로 구분되지 않는다. 덩어리마다 정답 다수결로 다시 칠하면 상한이 +2.6이었다.
- **방법:** 예측된 Si 영역(Primary + Eutectic)을 연결 덩어리로 나누고, 덩어리마다 23개 특징을 계산해 분류기(HistGradientBoosting)로 Primary/Eutectic을 다시 판정한다.
  - **모양:** 넓이(배율 보정), 최대·평균 두께, 둥근 정도, 볼록 정도, 외접 사각형 채움, 종횡비, 꼭짓점 수 → "크고 각진 다면체 vs 가늘고 불규칙"
  - **주변 (α-Al 할로):** 덩어리 둘레 띠의 Al·Al3Ni·Si 비율과 밝기 → "Primary Si는 α-Al 테두리로 둘러싸임"
  - **모델 확률:** 덩어리 안의 Primary Si·Eutectic Si 평균 확률, 확률 차이, 최댓값
  - **사진 단위:** 사진 전체의 Primary/Eutectic Si 비율, 저대비 여부, 해상도
- **확신할 때만 적용:** 분류기 확률이 80% 이상(또는 20% 이하)인 덩어리만 바꾼다. 모든 덩어리에 적용하면 애매한 중간 크기 덩어리에서 손해가 나서 +0.02에 그쳤다.
- **학습:** 90장의 OOF 예측으로 학습한다(제출용은 90장 전체, 효과 측정은 중첩 교차검증). 최종 구성에서 +0.083 [95% 구간 +0.04, +0.13].

## 4.7 한 상 전용 모델 섞기
- **아이디어:** "상마다 따로 판단한 뒤 합치면?"(팀 아이디어)에서 출발했다. 가장 약한 Eutectic Si부터 적용했다.
- **전용 모델:** 그 상인가 아닌가만 구분하는 2클래스 모델이다. 경계 가중은 그 상의 경계에 걸린다. 가는 구조에 유리한 2배 해상도로 학습했다.
- **합치는 방식 비교 (중첩 검증)**

| 방식 | 결과 |
|---|---|
| 먼저 구분하기 (전용 모델 확률이 기준을 넘으면 그 상으로 확정, 나머지는 앙상블이 결정) | −0.3 ~ −4.7. 전용 모델 단독 정확도(58.4)가 앙상블(59.1)보다 낮아 결정권을 주면 손해 |
| **섞기** (그 상의 확률만 일정 비율로 섞고 나머지 상은 비율 유지) | **Eutectic Si 전용 1종 +0.094, 2종 평균 +0.115, Al3Ni 전용 +0.04~0.06** |
| 대조: 같은 구조·해상도의 4상 모델로 같은 방식으로 섞기 | +0.000 |

- 대조 실험 덕분에 이득이 "2배 해상도 의견을 더 반영해서"가 아니라 **"한 상만 학습해서 다르게 틀리는 것"**에서 나온다는 것을 확인했다.
- 원래 해상도 전용 모델(−0.007)과 Al3Ni·Eutectic Si 두 상 전용 모델(기존 전용 모델 위에서 −0.003, 중복)은 넣지 않았다.
