# 2. 데이터 분석 (EDA)과 설계 결정

EDA의 목적은 "현상 기술"이 아니라 **모델 설계를 위한 근거 찾기**였다. 아래 표의 모든 발견은 실제 설계 결정으로 이어졌고, 나중에 실험으로 검증했다. (노트북: `eda/01_EDA.ipynb`, 그림: `eda/figures/`)

## 2.1 발견 → 결정 → 검증

| 발견 | 설계 결정 | 실험 검증 |
|---|---|---|
| 사진은 흑백인데 RGBA로 저장됨 | 1채널 흑백으로 읽음 | – |
| 사진마다 밝기·대비가 크게 다르고, **평가 세트는 저대비 사진이 60%** (p1 > 60: 평가 6/10, 학습 23/70, 검증 5/20) | 이미지별 **p1–p99 밝기 정규화** + 밝기 증강 | ✅ 저대비 사진 점수가 오히려 더 높게 나옴. 밝기 증강을 빼면 −1.03 (저대비 −1.69) |
| 같은 시야를 5가지 해상도(675·1096·1230·1278·1440 px)로 촬영. 675 px 사진에서 Al3Ni·Eutectic Si는 약 1.9 px | **675 px만 2배 확대**하는 배율 규칙 (정수 배율로 되돌림이 정확) | ✅ 빼면 675 px 사진에서 −1.6 |
| 완벽한 마스크도 1/2로 줄였다 되돌리면 mIoU 73.2 | 원본 해상도로 타일 처리. 낮은 해상도 모델 배제 | ✅ 1/4 해상도로 예측하는 SegFormer는 −1.5 |
| 가장 큰 Primary Si 덩어리 약 520 px | 학습 조각 512 px 이상 | – |
| 사진 모서리가 중앙보다 약 10 계조 어두움 (최대 28) | 조명 불균일 증강 | 효과 작음 (빼도 약 0) |
| **Primary Si가 없는 사진 2장** (A57_step1_sample3, A71_step2_sample1). Primary Si가 있으면 항상 이미지의 1.53% 이상 | Primary Si 후처리: 작은 조각 제거, 전체 0.5% 미만이면 모두 제거 | ✅ 해가 없음 (진짜 Primary Si를 지운 경우 0건) |
| Primary Si와 Eutectic Si가 거의 맞닿지 않음 (462 / 1,260만 경계 px) | 금속학적 해석(α-Al 할로) → Si 덩어리 분류기의 "주변" 특징 | 인접 규칙 후처리는 효과 0, 분류기는 +0.08~0.10 |
| 같은 합금의 사진이 학습·검증 세트에 걸쳐 있음 | **합금 번호 단위 5-fold 교차검증** | 정보 누수 방지 |
| 밝기만 쓰는 방법의 한계: k-means 39.5%, 이미지별 최적 밝기 구간 65.1% (Eutectic Si 29.8%) | 딥러닝 분할 필수, 모양·맥락 정보 필요 | – |
| 같은 합금에서 step 3·4로 갈수록 Al3Ni 증가(+4.7%p), Eutectic Si 감소(−2.5%p) (10쌍 중 9쌍) | 보고서 인사이트 과제 ("step = 냉각 조건?") | 두 step이 함께 있는 14개 합금에서 뒤 step일수록 Al3Ni 증가 11/14, 얇아짐 13/14, Eutectic Si 감소 12/14. 미세화는 냉각 속도 가설과 맞지만 Al3Ni 증가는 조성 변화도 시사 (6.5절) |
| 거의 같은 사진(중복) 없음. 이상해 보이는 A51·A74는 정답 확인 결과 정상 | 데이터 정제 불필요 | – |

## 2.2 클래스 분포
- 평균 면적 분율(정답 기준): α-Al 약 58%, Al3Ni 약 24%, Si(Primary + Eutectic) 약 17~18%. Eutectic Si는 약 7%.
- 질량 수지로 환산하면 Al–14.3Si–13.6Ni에 해당한다(밀도 Al 2.70 / Al3Ni 3.96 / Si 2.33 g/cm³ 가정). KIMS 계열 합금(Si 약 18%)이라면 정답의 Si 면적이 약 4%p 적은 셈이어서, **얇은 공정 Si가 라벨에서 덜 칠해졌을 가능성**이 있다. 실제 조성은 공개되지 않아 확정할 수 없다(6장).

## 2.3 기준 모델의 오답 분석 (이후 방향을 정한 분석)
U-Net + ResNet34 기준 모델(검증 20장)의 오답을 분석했다.
- **틀린 픽셀의 79%가 정답 경계에서 1 px 이내**에 있다 → 경계 위치 문제가 핵심이다. 이 결과로 경계 가중 손실, 해상도 확대, 앙상블을 시도했다.
- Eutectic Si가 58.5%로 가장 약하다. 주된 혼동은 Eutectic Si → Al3Ni(12%), Al(9%)이다.
- 정답 경계 1 px 띠를 빼고 채점하면 mIoU가 79.7 → 88.0으로 오른다(12개 모델 앙상블 기준). 남은 오차의 상당 부분이 라벨 경계의 애매함임을 시사한다.
