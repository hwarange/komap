# 3. 데이터 처리

## 3.1 전처리 (학습·예측 공통)
1. **흑백 1채널로 읽기:** 원본은 RGBA로 저장된 흑백 사진이다.
2. **이미지별 밝기 정규화:** 사진마다 하위 1%·상위 99% 밝기를 0과 1로 늘린다(p1–p99 stretch). 저대비·고대비 사진의 상별 밝기가 같은 위치로 정렬된다.
3. **배율 맞춤:** 같은 시야를 해상도만 다르게 찍었으므로, 기준 폭 1280 px에 가장 가까운 **정수 배율**로 키운다. 675 px → 2배, 나머지 → 1배. 2배 해상도 모델은 기준 폭 2560 px로, 1096~1440 px → 2배, 675 px → 4배다. 정수 배율이라 예측을 원래 크기로 되돌릴 때 블록 평균이 정확하다.
4. **원본 해상도 출력:** 예측 확률을 원래 크기로 되돌린 뒤 채점·제출한다.

## 3.2 검증 체계 (모든 판단의 기준)
데이터가 90장뿐이라 0.1~0.3 수준의 차이를 믿을 수 있게 재는 것이 가장 중요했다.

| 설계 | 이유 |
|---|---|
| **학습+검증 90장을 합금 번호 단위로 5-fold** 교차검증 (`splits/folds5.json`, fold당 18장, 저대비 사진 수 균형) | 20장 검증은 흔들림이 크다. 같은 합금의 형제 사진이 학습과 검증에 나뉘면 점수가 부풀므로 합금 단위로 나눴다 |
| **마지막 에폭 모델로 채점** | 검증 점수가 가장 좋은 에폭을 고르면 같은 데이터로 고르고 채점하게 되어 점수가 부푼다 |
| **같은 사진끼리 비교 + 부트스트랩 95% 구간 + 개선된 사진 수** | 평균 하나로 판단하지 않는다. 채택 기준: 단일 모델은 +0.1 이상이고 95% 구간이 0보다 위 |
| **시드만 바꾼 기준 모델로 잡음 측정** | ResNet34 0.35, ConvNeXt 0.09, 2배 해상도 UNet++ 0.07. 기준 모델은 시드 2개 평균을 사용했다 |
| **중첩 교차검증** | 앙상블 구성, 전용 모델 섞는 비율, 판정 기준처럼 **고르는 과정**이 있으면, fold마다 나머지 72장에서 고르고 남은 18장에 적용해 "정직한 추정"을 낸다 |
| **제출 코드 재현 검증** | 제출용 코드로 90장을 다시 예측해(각 사진은 그 사진을 학습하지 않은 모델만) 평가 코드와 점수가 일치하는지 확인했다 (예: 80.016 / 80.128 / 80.175 모두 일치) |
| **평가 사진은 학습에 쓰지 않음** | 규칙 준수. 의사 라벨, 자기지도 학습에도 쓰지 않았다 |

## 3.3 데이터 증강: 무엇을 쓰고 무엇을 뺐는가
학습할 때마다 **새로** 증강한다(온라인 증강). 1장당 에폭마다 8조각을 무작위로 잘라, 60에폭이면 약 3만 5천 개의 서로 다른 조각을 본다. 미리 만들어 재사용하는 방식(오프라인)보다 다양성이 커서 작은 데이터에서 과적합을 줄인다. 실제로 120에폭까지 늘려도 과적합 없이 계속 좋아졌다(2배 해상도 UNet++ +0.32).

**채택한 증강 (근거 포함)**
| 증강 | 근거 |
|---|---|
| 밝기 증강 (감마, 대비·밝기, 조명 불균일, 흐림, 노이즈) | 모두 빼면 −1.03. 하나씩 빼 보니 **노이즈 −0.68, 감마 −0.23**이 핵심이고 나머지는 약 0 |
| **90° 회전 + 좌우 반전만** (임의 각도 회전 대신) | 보간 없이 픽셀만 옮겨 가는 구조가 손상되지 않고, 예측 때 8방향 TTA와 같은 변환이라 일관성이 생김. UNet++ +0.17, 2배 해상도 +0.32, MiT +0.28 |
| 무작위 자르기 + 크기 ±15% | 기본 |

**시험했지만 뺀 증강 (두 구조에서 시험한 것 포함)**
| 증강 | 결과 | 원인 분석 |
|---|---|---|
| 저해상도 흉내 | −0.18 | 1~2 px Eutectic Si를 이미지에서 지움 |
| 상 기준점 히스토그램 매핑 | −0.22 | 저대비 문제가 정규화로 이미 해결돼 있었음 |
| 복사-붙여넣기 (Primary Si·Al3Ni) | −0.08 | 붙인 경계가 실제와 다름 |
| 탄성 변형 | −0.20 / −0.10 | 가는 판을 휘게 하고 라벨 테두리를 거칠게 만듦 |
| cutout (가린 곳은 손실에서 제외) | −0.06 / −0.06 | |
| mixup | −0.17 / −0.08 | 실제로 없는 겹친 조직을 만듦 |
| CutMix | −0.08 / −0.06 | 인공적인 네모 경계 |
| 오답 위치 위주로 자르기 | −0.24 / −0.10 | 평범한 조직을 볼 기회가 줄고 애매한 라벨을 반복 학습 |

→ **결론:** 실제 촬영에서 생기는 변화(밝기·노이즈·방향)를 흉내 내는 증강만 효과가 있었다. 1~4 px 구조의 **모양을 바꾸는 증강은 모두 Eutectic Si를 떨어뜨렸다**(−0.04 ~ −0.37).

## 3.4 라벨 처리
- 4색 마스크를 클래스 번호(0 Al, 1 Al3Ni, 2 Primary Si, 3 Eutectic Si)로 변환했다. 정해진 4색 외의 색은 "무시(255)"로 두어 손실에서 뺄 수 있게 했다(외부 데이터·cutout용).
- 정답과 예측에 모두 없는 상은 IoU 계산에서 제외했다(대회 규칙과 동일).
- 라벨 정제(경계 다시 긋기)는 시도했으나 효과가 없어 원래 라벨을 그대로 썼다. 밝기 기준으로 경계를 다시 판정하면 모든 설정에서 악화됐다. 정답 경계가 밝기 경계를 따르지 않는다는 뜻이다.

## 3.5 외부 데이터 검토
대회 측이 외부 데이터 사용을 허용하여, 공개 데이터 약 15종을 검토했다. **우리 네 상과 맞는 공개 광학현미경 데이터는 없었다.**

| 데이터 | 검토 결과 | 판단 |
|---|---|---|
| MICAST (RWTH 아헨, AlSi6Cu4Fe, CC BY 4.0) | 직접 내려받아 확인: 배경이 실제 조직이 아닌 **잡음 무늬** 위에 공정 Si·AlFeSi 조각을 따로 붙인 **합성 사진** | 1,000장으로 사전학습(공정 Si → Eutectic Si, AlFeSi 무시) → 우리 90장 미세조정: **−0.42** [−0.75, −0.11], Eutectic Si −0.80. 합성 맥락이 잘못된 단서를 가르쳐 **확실히 손해** |
| MicroSteel (Fe–TiB₂ 강, MIT) | 직접 확인: 광학현미경이 아니라 **SEM** 사진 (정보 줄에 SEM ×10,000 표기) | 79장으로 사전학습 → 우리 90장 미세조정: **−0.09** [−0.31, +0.12] (ConvNeXt 기준 79.19 대비). 시드 잡음 수준이라 효과 없음 |
| ASAD / MicroAl (Al 합금, Si·Fe상 라벨) | **학술 전용**, 5xxx·6xxx 합금의 입자 조직, 배율 0.1 µm/px | 라이선스·도메인 문제로 제외 |
| SemiRCF (Al–12.7Si) | 결정립 경계 라벨만 있음, **라이선스 없음** | 제외 |
| MetalDAM, UHCSDB, Aachen-Heerlen 등 | SEM 데이터. SEM으로 학습한 모델을 OM에 쓰면 성능이 크게 떨어짐 (Goetz 2022: 49.7%) | 제외 |
| MicroNet (현미경 10만 장 사전학습 가중치) | 직접 시험: ImageNet 대비 −0.11 / −0.21. 원 논문도 학습 이미지 10장 이상에서는 ImageNet과 차이 없음 | 제외 |
