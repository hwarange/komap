# 5. 실험과 성능

## 5.1 평가 방법 요약
- 모든 수치는 **90장 합금 단위 5-fold 교차검증 mIoU**(8방향 TTA + 후처리)다. 3장 참조.
- 차이는 같은 사진끼리 비교한 평균(Δ)과 부트스트랩 95% 구간 [하한, 상한], 개선된 사진 수로 보고한다.
- 고르는 과정이 있으면 중첩 교차검증(정직한 추정)만 판단에 쓴다.
- 실험 기간 2026-10-04 ~ 10-07, 서버 L40S × 4. 학습 약 450회(교차검증 88개 설정의 fold 학습 430회 + 90장 전체 학습 18회), 실행 실패 0건.

## 5.4 결과에서 읽은 패턴
1. **효과가 있던 것:** "더 세밀하게 보기"(해상도), "더 오래 보기"(에폭), "다르게 틀리는 모델 섞기"(앙상블·전용 모델), "데이터 특성에 맞춘 처리"(정규화·배율·TTA·금속학 분류기)
2. **효과가 없던 것:** "모델을 바꾸기"(크기·사전학습·구조)와 "학습 신호를 바꾸거나 더하기"(손실 가중, 부드러운 정답, 증강, 오답 위주, 필터)
3. 최신 U-Net 비교 연구의 결론과 같다. U-Bench(2025)에서 U-Net 변형 100개 중 80% 이상이 기본 U-Net보다 유의하게 낫지 않았고, 실패 원인 1위는 흐릿한 경계였다.

## 5.5 안정성 점검
- **시드 잡음:** 최고 모델의 두 시드 차이는 −0.07 [−0.32, +0.15]로 작다. 80.03은 운이 아니었다.
- **90장 전체 학습 모델:** 학습한 사진 점수(82.7~82.9)가 같은 사진의 OOF 점수(80.6)보다 높아 학습이 정상이다. 시드 간 불일치(1.13%)가 fold 모델끼리(1.52%)보다 작다.
- **제출본 간 차이:** sub5는 sub2와 픽셀 1.06%, sub4와 0.68% 다르다. 모든 이미지에서 2% 미만이다.
