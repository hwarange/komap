# 7. 독창성

이 과제를 위해 새로 설계하거나 이 데이터에 맞게 처음 적용한 방법과 그 근거다.

## 7.1 금속학 특징 기반 Si 덩어리 분류기
- **문제:** Primary Si와 Eutectic Si는 같은 결정상이라 밝기로 구분할 수 없다. CNN이 덩어리 단위로 헷갈리는 경우가 남는다(경계에서 떨어진 Eutectic Si의 15.8%를 Primary Si로 예측).
- **방법:** 분할 결과를 연결 덩어리로 나누고, 금속학 지식을 특징으로 옮겨 덩어리 단위로 다시 판정한다.
  - Primary Si는 크고 각진 다면체 → 넓이, 두께, 볼록 정도, 꼭짓점 수
  - Primary Si는 α-Al 테두리(할로)로 둘러싸임 → 덩어리 둘레 띠의 상 비율
  - Eutectic Si는 가늘고 불규칙 → 종횡비, 둥근 정도
- **설계 포인트:** 분류기가 80% 이상 확신할 때만 바꾼다. 모든 덩어리에 적용하면 +0.02였지만, 확신할 때만 적용하면 +0.08~0.10이었다.
- **근거:** 덩어리 단위 상한(+2.6)을 먼저 재서 가능성을 확인했다. 효과는 중첩 교차검증으로 쟀다.

## 7.2 한 상 전용 모델을 "의견"으로 섞기 (대조 실험으로 원리 확인)
- 팀 아이디어("상마다 따로 판단한 뒤 합치면?")를 가장 어려운 상(Eutectic Si)에 적용했다.
- **결정권을 주는 방식(먼저 구분하기)은 실패하고(−0.3 ~ −4.7), 의견으로 섞는 방식은 성공했다(+0.09~0.12).**
- **대조 실험:** 구조·해상도가 같은 4상 모델로 똑같이 섞으면 효과가 0이었다. 이득이 "한 상만 학습해서 다르게 틀리는 것"에서 나온다는 것을 분리해 확인했다.
- 인코더가 다른 전용 모델 2종을 평균하면 더 좋았고(+0.115), 같은 원리를 두 번째로 약한 상(Al3Ni)에도 확장했다.

## 7.3 EDA에서 출발한 처리 설계
- **같은 시야·다른 해상도라는 관찰 → 정수 배율 규칙.** 675 px 사진만 2배로 키웠다(675 px 사진 +1.6). 정수 배율이라 예측을 원래 크기로 되돌릴 때 손실이 없다. 정수가 아닌 배율에서는 되돌리는 과정만으로 정답이 97.85까지 떨어지는 것을 직접 확인했다.
- **평가 세트의 저대비 편중(60%) → 이미지별 정규화 + 밝기 증강 + 저대비 비중을 반영한 평가 환산.**
- **"해상도를 1/2로 줄이면 완벽한 마스크도 73.2"라는 상한 분석 → 원본 해상도 타일 처리 + 2배 해상도 모델.** 2배 해상도는 최고 단일 모델(80.03)이 됐다.

## 7.4 라벨 한계를 정량화하는 분석 틀
- 오답 위치, 경계 띠 제외 채점, 학습 사진 채점, 판정 기준 대칭성, 정답 1 px 팽창 IoU(62.3), IoU = w/(w+2δ)를 한 틀로 묶었다. 이로써 **"Eutectic Si 약 60은 라벨 일치 수준"**임을 여러 독립된 방법으로 보였다(6.1절).
- 이 분석 덕분에 효과가 없을 방향(경계 강조 손실, 칠하는 양 조정)을 미리 예측하고, 남은 자원을 해상도·앙상블 다양성에 집중할 수 있었다.

## 7.5 거짓 결론을 막는 검증 체계
- **중첩 교차검증:** 앙상블 구성·섞는 비율·분류기처럼 고르는 과정을 모두 중첩 검증으로 평가했다. 예를 들어 자동 선택 앙상블은 같은 데이터로 재면 80.39이지만, 정직한 추정은 80.17이었다.
- **"두 번째 기회" 원칙:** 설정 문제로 실패했을 수 있는 아이디어는 다른 설정으로 한 번 더 시험했다(Skeleton 손실, DINOv3, ConvNeXt-S, Si 분류기 적용 범위). 그 덕분에 Si 분류기를 놓치지 않았다.
- **같은 원리의 대조 실험:** 전용 모델 vs 4상 모델 섞기, 사전학습만 다른 MicroNet vs ImageNet
- **이상 패턴은 코드부터 의심:** 크기 TTA에서 1.1배와 1.25배가 같은 폭으로 떨어지는 이상 패턴을 보고, 확률을 원래 크기로 되돌리는 코드의 버그(정수가 아닌 배율에서 확률을 흐림)를 찾아 고쳤다.

## 7.6 금속학 가설을 데이터로 검증
- 규칙/불규칙 공정 가설(배열 방향 일관성)을 측정으로 기각했다(AUC 0.51).
- 질량 수지로 정답 마스크의 Si 면적이 합금 조성과 맞는지 점검했다(6.3절).
- 상 분율 → 탄성률(Hashin–Shtrikman) 범위가 KIMS 실측값과 일치함을 확인했다(6.4절).
