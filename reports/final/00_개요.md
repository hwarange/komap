# 고탄성 알루미늄 합금 광학현미경 이미지 상 분할: 최종 보고서 개요

> 2026 KoMaP AI 경진대회 「고탄성 알루미늄 합금 이미지 상 분할 AI 모델 개발」
> 작성: 2026-10-07 (초안). `[추가 분석 예정]`으로 표시한 부분은 보고서 완성 전에 채운다.

## 1. 한 줄 요약
가는 판상(1~4 px) 공정 Si가 핵심 난제인 Al–Si–Ni 주조 합금 광학현미경(OM) 이미지에서 **데이터 특성 분석(EDA)으로 전처리·검증 체계를 설계**하고, **구조가 다른 모델의 앙상블에 "한 상 전용 모델"과 "금속학 특징 기반 Si 덩어리 분류기"를 결합**하여 90장 교차검증 mIoU **약 80.2**(기준 모델 78.3 대비 +1.9)를 달성했다. 남은 오차의 대부분은 **정답 경계 1 px의 애매함**에서 오며, 이는 라벨·광학 분해능의 한계로 정량 확인했다.

## 2. 최종 결과

| 구분 | 내용 | 90장 CV mIoU (정직한 추정) |
|---|---|---|
| 기준 모델 | U-Net + ResNet34, EDA 기반 전처리 | 78.31 |
| 최고 단일 모델 | 2배 해상도 UNet++ (ResNet34), 120 에폭, 경계 가중, 90° 회전 증강 | 80.03 |
| **최종 제출 (sub5)** | 27개 실험 × 5-fold 앙상블 + Eutectic Si 전용 모델 2종 + Al3Ni 전용 모델 + Si 덩어리 분류기 | **약 80.23** |

- 상별 IoU (최종 구성, Si 분류기 적용 전 기준): α-Al 93.2 / Primary Si 89.1 / Al3Ni 79.4 / Eutectic Si 59.5
- 평가 세트 구성(저대비 이미지 60%)으로 환산한 예상 점수: 약 81 (평가 이미지가 10장이므로 ±2~3%p 변동 가능)
- 정직한 추정: 앙상블 구성·섞는 비율 등 **무언가를 고르는 모든 단계는 중첩 교차검증**으로 평가하여, 같은 데이터로 고르고 채점할 때 생기는 점수 부풀림을 제거했다.

## 3. 핵심 발견 다섯 가지
1. **해상도가 가장 확실한 개선 수단이다.** 입력을 2배로 키운 모델이 Eutectic Si를 +0.76 개선했다. 반면 더 큰 모델·최신 사전학습(DINOv3, 현미경 사전학습 MicroNet)·Transformer는 효과가 없었다.
2. **학습 신호를 바꾸거나 더하는 방법은 이 데이터에서 일관되게 실패했다.** 경계 가중 강화, 경계 부드러운 정답(BLS), 오답 위주 학습, 탄성 변형·cutout·mixup·CutMix, 필터 입력 채널이 모두 Eutectic Si를 떨어뜨렸다. 1~4 px 구조의 모양을 바꾸거나 애매한 라벨을 강조하면 해가 된다.
3. **한 상만 학습한 "전용 모델"은 앙상블에 30~40% 섞을 때 효과가 있다.** 같은 구조의 4상 모델로 섞으면 효과가 0이었으므로(대조 실험), 이득은 "다르게 틀리는 모델"에서 나온다.
4. **금속학 지식이 후처리에서 효과를 냈다.** Primary Si는 크고 각진 다면체이고 α-Al 테두리(할로)로 둘러싸이며, Eutectic Si는 가늘고 불규칙하다는 특징으로 만든 덩어리 분류기가 +0.08~0.10을 더했다.
5. **남은 오차는 라벨 경계의 애매함이다.** 오답의 79%가 경계 1 px 이내이고, 정답 Eutectic Si를 1 px 두껍게 그리기만 해도 원래 정답과의 IoU가 62.3이다. 모델의 59.5는 이 수준과 같다.
6. **IoU가 낮아도 재료 분석에는 실용적이다.**
   - Eutectic Si는 IoU 59.5지만, 상 분율의 상대 오차 중앙값은 10.6%로 수동 점계수법의 관행 정밀도(약 10%)와 비슷하다.
   - 예측 분율로 추정한 탄성률(Hashin–Shtrikman)은 정답 대비 사진당 평균 1.2 GPa 차이로, 사진 간 실제 차이(5.5 GPa)보다 훨씬 작다.
   - 모델 예측만으로 step에 따른 조직 변화 경향(Al3Ni 증가·미세화)을 정답과 같은 방향으로 재현했다.
