## 8.2 코드 구성 (`src/`)
| 파일 | 역할 |
|---|---|
| `data.py` | 데이터 로딩, 정규화, 배율 규칙, 증강, 합금 단위 fold |
| `train.py` | 학습 (fold 단위, 마지막 에폭 모델 채점, OOF 예측 저장) |
| `infer.py` | 슬라이딩 윈도우 예측, 8방향 TTA, IoU, Primary Si 후처리 |
| `launch.py` | 실험 목록을 5-fold 작업으로 펼쳐 GPU에 배치 |
| `ensemble.py` | OOF 앙상블 평가 (전체 평균, 탐욕적 선택 + 중첩 검증) |
| `decision_rules.py` | 전용 모델 섞기, 판정 규칙의 중첩 검증 |
| `si_classifier.py` | Si 덩어리 분류기 (`cv` 중첩 평가, `fit` 제출용) |
| `submit.py` | 제출 예측 (모델별 저장 → 섞기 → 후처리 → 4색 PNG) |
| `verify_cv_blend.py` | 제출 코드로 90장 재현 검증 |

## 8.3 재현 절차 (요약)
1. 실험 목록대로 5-fold 학습: `python src/launch.py experiments/<목록>.txt --gpus 0 1 2 3 --per-gpu 2`
2. OOF 앙상블 확률 저장과 섞는 비율 평가: `bash scripts/eval_final_combo.sh A27 <27개 실험>`
3. Si 분류기 학습: `python src/si_classifier.py fit --exps _ens_A27_sie_al --out runs/si_clf/sub5_model.pkl`
4. 제출 예측과 조합: `bash scripts/run_sub5.sh`
   - 평가 사진 예측: `submit.py predict --split test`
   - 조합: `submit.py combine --recipe <27개> --sie-spec sie_x2_unetpp sie_x2_cnx --sie-alpha 0.4 --al3ni-spec al3ni_x2_unetpp --al3ni-alpha 0.3 --si-clf ...`
5. 자세한 명령은 `submissions/sub4/README.md`, `scripts/run_sub5.sh`에 있다.

## 8.4 제출물
- **파일:** `masks/<사진이름>_mask.png` 10개. 원본과 같은 크기의 RGB PNG이고, 대회 4색만 쓴다.
- **최종 후보:** `submissions/sub5` (fold 모델만) 또는 `submissions/sub5_full` (90장 전체 학습 모델 포함, 비중 약 10%). 두 판의 차이는 픽셀 0.03%이다. `[최종 선택 기입 예정]`

## 8.5 제출물 검증
| 점검 | 결과 |
|---|---|
| 제출 코드 재현 (90장, 각 사진은 학습하지 않은 모델만) | 앙상블 80.016 / Eutectic Si 섞기 80.128 / Al3Ni 섞기 80.175로 평가 코드와 일치 |
| 형식 | 크기, RGB, 4색 모두 통과 |
| 이전 제출본과의 차이 | sub2 대비 1.06%, sub4 대비 0.68% (모든 사진 2% 미만) |
| Si 분류기가 바꾼 픽셀 | 사진당 평균 0.046% (최대 0.14%) |
| 90장 전체 학습 모델 | 학습 사진 점수 82.7~82.9 (> OOF 80.6), 시드 간 불일치 1.13% (fold 모델 1.52%) |
| 평가 이미지 사용 | 학습·선택·보정 어디에도 쓰지 않음 |
