### 해석
- **90° 회전의 효과는 모델에 따라 달라요.**

  | 모델 | 효과 |
  |---|---|
  | UNet++ (120에폭) | +0.17. TTA 없이도 +0.21, Eutectic Si +0.51 |
  | 2배 해상도 | +0.32 (경계 가중과 함께) |
  | MiT | +0.28 (경계 가중과 함께) |
  | ConvNeXt 60에폭 | +0.16 |
  | **ConvNeXt 120에폭** | **−0.12** |

  ConvNeXt에서는 60에폭과 120에폭의 결과가 반대로 나와서 "불확실"로 정정했어요. 오래 학습할수록 임의 각도 회전이 과적합을 막는 역할을 했을 가능성이 있어요(학습 손실 0.411 vs 0.427).

- **밝기 증강 하나씩 빼기:**

  | 뺀 증강 | 효과 |
  |---|---|
  | 노이즈 | **−0.68** (저대비 −1.54, Eutectic Si −1.67, Eutectic Si 과소 예측 0.934배) |
  | 감마 | −0.23 |
  | 대비 | −0.07 |
  | 블러 | −0.06 |
  | 조명 | −0.04 |

  다섯 개의 합(−1.08)이 한꺼번에 뺐을 때(`a_noint` −1.03)와 거의 같아요. 효과가 서로 독립적이에요. 4단계 후 "블러도 해로울 수 있다"고 의심했는데 **틀렸어요.** 약한 블러는 무해하고, 해로웠던 건 강한 축소(저해상도 흉내)였어요.
- **EMA (−0.16):** 학습률이 코사인으로 0까지 줄어서 마지막 가중치가 이미 안정돼 있었어요. 거기에 BatchNorm 통계를 평균하지 않고 복사한 구현 선택이 겹쳤을 수 있어요. 재시도하지 않을게요.
- **경계 가중 5배 (−0.06):** 경계 가중은 "있느냐"가 중요하고, 크기에는 둔감해요. 지금 설정(3배)을 유지해요.

## 4. 학습 없이 시험한 추가 아이디어 (모두 OOF로 정직하게 평가)

| 아이디어 | 결과 | 배운 점 |
|---|---|---|
| **밝기로 경계 다시 긋기**: 경계 픽셀을 두 상 중 밝기가 가까운 쪽으로 | **−0.10 ~ −15** (모든 설정에서 악화) | 모델이 이미 밝기보다 경계를 잘 그어요. "정답이 밝기 경계를 따라 반자동으로 만들어졌다"는 가설은 **틀림** → 경계 1px 오차는 라벨링 애매함일 가능성이 커요 |
| **사용자 아이디어: 픽셀을 쪼개 예측하고 픽셀 안에서 투표** | 다수결 vs 확률 평균 −0.004 / 위치 이동 TTA(6위치) +0.027 [−0.012, +0.062] | 원리는 `x2` 실험으로 이미 반영돼 있어요(2배 해상도 순수 효과 약 +0.3). 다수결과 확률 평균은 같고, 위치 이동 투표는 효과가 미미해요 |
| **Eutectic Si 오답 진단** | 경계에서 떨어진 Eutectic Si 픽셀의 **15.8%를 Primary Si로** 예측. 30px 미만 작은 조각은 절반을 놓치지만 전체 Eutectic Si의 9%뿐 | Eutectic Si 문제의 상당 부분은 **같은 Si 결정인 Primary Si와의 덩어리 단위 혼동**이에요 |
| **Si 덩어리 정답 배정의 상한** | 79.73 → **82.33** | 덩어리 단위 판정이 가장 큰 남은 여지예요 |
| Si 덩어리 분류기 (모든 덩어리에 적용) | +0.02 | 덩어리 단위 정확도가 앙상블 96.22% vs 분류기 96.09%. 남은 오답은 **Primary와 Eutectic이 반반인 중간 크기 덩어리**에 몰려 있어요(라벨 애매함 추정) |
| **Si 덩어리 분류기 (확신 80% 이상일 때만)** | **+0.087** [+0.016, +0.155] (12개 앙상블) / **+0.100** [+0.040, +0.161] (16개 앙상블) | **채택.** 확신 기준을 70~95%로 바꿔도 모두 양수 |

**Si 덩어리 분류기 (`src/si_classifier.py`)**
- 앙상블이 예측한 Si 영역을 연결 덩어리로 묶어요.
- 덩어리마다 23개 특징을 계산하고, 그래디언트 부스팅으로 Primary Si인지 Eutectic Si인지 판정해요. 특징은 다음과 같아요.
  - 크기·두께 (배율 보정)
  - 볼록함·꼭짓점 수·종횡비
  - 덩어리 안 확률·밝기
  - 주변 고리의 상 구성 (α-Al 할로)
  - 사진 전체의 상 분율
- 금속학 근거: Primary Si는 크고 각지며 α-Al 할로에 둘러싸이고, Eutectic Si는 가늘고 불규칙해요.
- 실제로 중요했던 특징은 크기와 덩어리 안 확률이었고, 모양·할로 특징의 기여는 작았어요.
- 처음에 "모든 덩어리에 적용" 결과(+0.02)만 보고 "쓰지 않는다"고 했다가, 사용자 질문으로 적용 범위를 바꿔 보고 결정을 바꿨어요.

## 6. 2차 제출본 (`submissions/sub2`)
- **구성:** 위 16개 실험 × 5-fold = 80개 모델의 평균 + 8방향 TTA + Primary Si 후처리 + Si 덩어리 분류기(확신 80%)
- **검증:**
  - 같은 제출 코드로 90장을 OOF 방식으로 돌린 결과 79.857이에요. 앙상블 평가와 일치해요.
  - 형식 검사(크기, RGB, 4색)를 통과했어요.
- **Si 분류기가 평가 사진에서 바꾼 픽셀:** 0.002~0.15%. 90장에 적용했을 때(평균 0.23%)보다 작아서, 학습 때와 제출 때 입력 차이로 인한 이상은 없어요.
- **1차 제출본과의 차이:** 사진당 픽셀 0.4~0.9%
- **예상 성능:** CV **79.96** (앙상블 79.86 + 분류기 +0.10). 평가 세트 구성으로 환산하면 약 80.6~80.7

## 7. 자기 점검 (4·5단계 전체)
1. **조사 아이디어를 우리 데이터 특성과 맞춰 보지 않고 우선순위를 매겼어요.** 저대비 대응 증강과 저해상도 흉내가 그 예예요. → 앞으로는 "우리 데이터에 그 문제가 실제로 있는지"를 먼저 확인해요.
2. **효과를 너무 빨리 일반화했어요.** "90° 회전 효과가 다른 구조에서도 재현됐다"고 했다가, ConvNeXt 120에폭에서 반대로 나와 정정했어요.
3. **손실 가중치 보정을 빠뜨렸어요 (Skeleton 손실).** 예측 면적 비율 점검을 넣어 둔 덕분에 원인을 바로 찾았어요.
4. **상한(+2.6)을 실현 가능한 이득으로 착각했어요.** 덩어리 단위 정확도를 먼저 쟀다면 기대를 일찍 낮출 수 있었어요.
5. **단일 설정만 보고 "버린다"고 판단했어요 (Si 분류기).** 적용 범위를 바꿔 보는 건 몇 분이면 되는 일이었어요.
6. **운영 실수:** 감시 스크립트의 종료 코드 처리, 테스트 로그를 먼저 지운 것, 원격 명령의 따옴표 충돌. 결과에는 영향이 없었어요.
